# Build the interface on shadcn/ui with Base UI, restyled into Ohana's own visual language

The web client uses shadcn/ui components on Base UI primitives, styled with Tailwind CSS v4. The shadcn CLI copies component source into the repository rather than installing a styled dependency, so Ohana owns and edits every component; Base UI supplies accessible behaviour (focus, keyboard, ARIA, positioning) without imposing appearance. The default shadcn theme is only a starting point: the design system replaces its palette, typography, radii, spacing, shadows, and iconography with Ohana's own tokens so the product does not look like a default template. A fully custom component set was rejected because it would spend the project's effort on solved accessibility problems.

Glass is a design-system material, not a global style. It is a frosted translucent surface (backdrop blur and saturation over a tinted fill) used for floating chrome such as navigation bars, the tab bar, sheets, and popovers, never behind long-form text such as journal entries. True liquid-glass refraction through `backdrop-filter: url()` SVG filters renders only in Chromium; iPhones, Ohana's main installed platform, use WebKit and would never show it, so it is not part of the design system. Glass surfaces fall back to an opaque fill when `prefers-reduced-transparency` is set, when `backdrop-filter` is unsupported, and wherever text on them would miss WCAG contrast.
