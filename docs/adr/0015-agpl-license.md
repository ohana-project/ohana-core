# License Ohana under AGPL-3.0

Ohana is licensed under the GNU Affero General Public License v3.0 instead of the Apache-2.0 license it started with. Anyone who offers a modified Ohana to users over a network must make that modified source available to them. This keeps the project from becoming the base for a closed hosted service for families, which matters because hosting for unrelated families is a planned direction.

AGPL-3.0 is an OSI-approved open source license. The trade-off is that some organisations restrict AGPL dependencies internally, which may deter a few contributors or integrators. The switch happened before any external contributions, so no relicensing consent was needed; a later change would require the agreement of every contributor or a contributor licence agreement.
